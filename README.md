# AI Professional Productivity Hub

A browser-based professional productivity workspace demonstrating practical skills in **AI workflows, frontend development, UX, education technology, research, administration and digital transformation**.

> **Portfolio proposition:** instead of only describing AI and digital-transformation capability, this project provides visible evidence of building and shipping a working workflow-oriented application.

## MVP capabilities

### 1. Professional Dashboard
- Today's and priority task management
- Add, complete and delete tasks
- Productivity statistics
- Quick access to AI workflows
- Meeting-planning entry point
- Persistent scratchpad

### 2. AI Email Assistant
- Email purpose and audience inputs
- Tone selection
- Important context/details
- Structured professional email output
- Copy-to-clipboard

### 3. Meeting Assistant
- Meeting title and participants
- Agenda and notes
- Decisions
- Action points with responsible person/deadline notation
- Structured meeting record
- Copy-to-clipboard

### 4. Research Assistant
- Research topic/title
- Research question
- Keywords
- Literature-review structure
- Research objectives
- Source capture
- Evidence/notes
- Findings
- Synthesis
- Local persistence and research-brief export to clipboard

### 5. Teacher Assistant
- Subject/topic and grade/level
- Duration and learner context
- Learning objectives
- Learning activities
- Assessment
- Differentiation
- Digital resources
- Structured lesson-plan output

### 6. Prompt Library
Prompts are organized around practical professional work including:
- Executive Support
- Teaching & Learning
- Research
- Business
- Marketing
- Writing
- AI Productivity
- Related academic/administrative workflows

Features include search, category filtering, favorites, prompt detail and copy-to-clipboard.

### 7. Document Drafting Workspace
- Academic, professional, research and business document types
- Title, audience and purpose
- Outline builder
- Research/source notes
- Bring research context into drafting
- Persistent draft editor
- Word count
- Copy complete document

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage
- GitHub
- Responsive Web Design

The MVP intentionally uses structured/template responses before external AI APIs are introduced. This validates the user experience and workflow before adding backend infrastructure and AI-provider dependencies.

## Run locally

Open `index.html` directly in a modern browser, or serve the repository using any static web server.

No API key or database is required for the MVP.
