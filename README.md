# AI Professional Productivity Hub

A lightweight, browser-based professional workspace for managing priorities, capturing notes, researching, and starting repeatable AI-assisted workflows.

## Current version

### Dashboard
- Daily priority task list
- Add, complete, and delete tasks
- Quick-start workflow templates
- Persistent scratchpad using browser local storage
- Focus mode foundation
- Responsive layout for desktop and mobile

### Prompt Library
- 22 professional and academic prompts
- 8 categories
- Search and category filtering
- Favorites persisted locally
- Prompt detail view
- Copy-to-clipboard
- Empty states

### Research Workspace
- Research project title and research question
- Objectives capture
- Source capture with title, author, type, and URL
- Evidence and notes area
- Key findings area
- Synthesis/draft insight area
- Live project snapshot
- Copy complete research brief
- Local persistence
- Clear workspace action

## Run locally

Open `index.html` directly in a browser, or serve the repository with any static web server.
